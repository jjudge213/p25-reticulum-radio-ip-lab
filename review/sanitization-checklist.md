# Sanitization Checklist

Use this checklist before adding new public assets.

- [x] Current public narrative excludes operational details and sensitive identifiers.
- [x] Source-platform provenance reduced to private-source/public-safe-derivative language.
- [x] Text scan checked for credentials, codeplugs, key material, restricted manuals, private IPs, and source URLs.
- [x] Asset metadata spot-check completed with `exiftool`.
- [ ] Repeat full-resolution visual review before adding any new radio-display, terminal, map, or vehicle media.
